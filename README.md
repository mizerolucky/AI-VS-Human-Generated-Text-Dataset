# LLM - Detect AI Generated Text

A data exploration repository for studying human-written and AI-generated essays using the Kaggle **LLM - Detect AI Generated Text** dataset.

The project includes the official training and test files, prompt data, an additional labeled essay dataset, and a Jupyter Notebook for loading, validating, and exploring the data before building classification models.

## Dataset Files

### `train_essays.csv`

Official training essays used for model development.

Typical columns include:

- `id` — unique essay identifier
- `prompt_id` — identifier of the writing prompt
- `text` — essay content
- `generated` — target label

Target meaning:

```text
0 = Human-written essay
1 = AI-generated essay
```

### `test_essays.csv`

Competition test essays used for generating predictions.

Typical columns:

- `id`
- `prompt_id`
- `text`

The `generated` column is not included because it is the value a model must predict.

### `train_prompts.csv`

Contains information about the writing prompts associated with the essays.

It can be used to understand how essays are distributed across different topics and prompts.

### `sample_submission.csv`

Shows the expected format for competition predictions.

A model should generate a probability for the `generated` column for every test essay.

### `Training_Essay_Data.csv`

Additional labeled training data containing essay text and AI-generation labels.

This file is tracked using **Git LFS** because of its size.

If the repository was cloned and this file contains only a Git LFS pointer, run:

```bash
git lfs pull
```

## EDA Notebook

### `llm_detect_ai_generated_text_eda.ipynb`

The notebook performs the main data loading and exploratory analysis steps.

It includes:

- Loading all CSV files
- Dataset shape and column inspection
- Missing-value checks
- Duplicate-row detection
- Duplicate-text detection
- Target class distribution
- Essay character counts
- Essay word counts
- Sentence counts
- Average word-length analysis
- Human vs AI essay-length comparison
- Prompt distribution analysis
- Train vs test comparison
- Official vs additional training-data comparison
- Text-overlap and possible leakage checks
- Example human and AI-generated essays
- Sample submission validation

## Example Data

An essay dataset may have a structure similar to:

```text
id        prompt_id    text
0000aaaa  2            Aaa bbb ccc.
1111bbbb  3            Bbb ccc ddd.
2222cccc  4            CCC ddd eee.
```

For labeled training data, a `generated` column is also included.

## Project Goal

The goal of this repository is to understand the characteristics of human-written and AI-generated essays before training a machine learning model that can estimate whether a given essay was generated by an AI system.
